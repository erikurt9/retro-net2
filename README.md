# RETRO-NET

Archivo retro-moderno de cultura pop. React + Vite + Tailwind + Lucide.

    npm install
    npm run dev

Atajo: `/` enfoca el buscador. Flechas izquierda/derecha cambian de pestaña.
Todo el código y los datos de prueba están en `src/App.jsx` (un solo archivo). Fotos, audio y video son simulados.
